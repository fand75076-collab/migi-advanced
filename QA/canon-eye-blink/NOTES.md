# Canon 眼睛与眨眼验收(v0.13.0 之后代码改动)

本次不改图集,只改程序化眼睛与行为参数:

1. **眼睛去彩色虹膜**:删除橄榄绿 `iris`/`irisDark` 两层,纯黑瞳放大到
   `0.44 × sourceRadius`(原瞳孔仅 0.20),大高光删除,只留一颗 0.05 静态
   弱高光(alpha 0.85);眼白半径 0.82 → 0.94,完全遮住原画眼球区域,
   避免部分帧图集里残留的橄榄色瞳孔在边缘漏出。贴合动画版 Migi 白底黑瞳
   的死物式注视。
2. **眨眼纪律**:调度间隔 3.5–8.5s → 16–38s,时长 0.13–0.22s → 0.30–0.44s;
   动画闭合 0.055s→0.09s、释放 0.085s→0.15s;每只眼按索引错相 0.045s
   (上限 3 眼),不再全体同步眨。
3. **异步分视**(运行时行为,QA 图不可见):`gaze` 仍是主眼的共享目标,
   分支眼(index≥1)在常态下按各自的低频双层正弦游走目标自主扫视;
   多 Agent 并行(`activeAgentCount > 1`)时分支眼额外向左右扇区偏置。
   点击/悬停注意信号、强制 QA 凝视、睡眠/渐醒阶段、以及一切确定性 QA
   运行都会平滑汇聚(响应 2.6/s),汇聚瞬间即"它注意到你了"。
